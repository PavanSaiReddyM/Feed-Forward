# Feed-Forward – Food Waste Management App

> Connect. Share. Reduce Waste.

Food Saver is a mobile application built using React Native and Firebase that helps reduce food wastage by connecting food donors (restaurants, event hosts) with NGOs and orphanages.

---

## 📌 Problem Statement

Large amounts of food are wasted daily from restaurants, events, and households, while many people suffer from hunger.

There is no efficient real-time system connecting food donors and NGOs.

**Food Saver solves this problem by providing a digital platform that connects donors and NGOs in real-time.**

---

## 🚀 Features

### 👤 User Roles
- 🏢 Donor (Restaurant / Event Host)
- 🤝 NGO / Orphanage
- 🛠️ Admin

---

### 🔐 Authentication
- Email & Password login
- Role-based registration
- Role-based redirection after login

---

### 🍱 Donor Features
- Post food donation
- View active donations
- View donation history
- Profile management
- Track impact score

---

### 🤝 NGO Features
- View available food donations
- Request food
- Track pickup status
- View request history
- Profile management

---

### 🛠️ Admin Features
- View total users
- Monitor completed donations
- Verify NGOs
- View and manage complaints
- Approve / Reject NGOs

---
